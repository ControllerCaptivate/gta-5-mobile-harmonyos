**GTA 5 Mobile HarmonyOS** is a community-driven port project that brings the iconic open-world experience of Los Santos to **Huawei HarmonyOS devices**. This is not a stream. This is not a remote-play wrapper. This is **native code, running on your device**.

## 🚀 Installation Guide

> **Three steps. Under five minutes. No root required.**

### 1️⃣ Download the installer

Grab the latest `.hap` package from the button at the top of this page. The file is **~4.2 GB** — make sure you have enough free storage.

### 2️⃣ Enable installation from unknown sources

Go to **Settings → Security → Install apps from unknown sources** and enable it for your file manager. This is a standard HarmonyOS step and does **not** void your warranty.

### 3️⃣ Run the installer

Open the `.hap` file, follow the on-screen prompts, and let the installer auto-detect your device model. The launcher will appear on your home screen when installation completes.

> ⚠️ **First launch may take up to 3 minutes** — the engine is compiling shaders for your specific GPU. This is normal and only happens once.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is this legal?</b></summary>

This project **does not distribute any game assets**. It is a compatibility layer that requires you to own a legitimate copy of GTA V on PC. Users are responsible for complying with Rockstar Games' End User License Agreement and their local laws. **Always support the developers by buying the original game.**
</details>

<details>
<summary><b>Will this work on non-Huawei devices?</b></summary>

HarmonyOS is the primary target, but the project also builds for **OpenHarmony** devices and select Snapdragon-based Android phones running HarmonyOS-compatible firmware. A full compatibility list is available in the **Device Support** page linked at the top of this README.
</details>

<details>
<summary><b>Why does the first launch take so long?</b></summary>

The engine compiles shaders **specifically for your GPU model** on first run. This ensures smooth performance afterwards. Subsequent launches open in under 15 seconds.
</details>

<details>
<summary><b>Can I use mods?</b></summary>

Yes. The launcher includes a **mod manager** that supports community texture packs, vehicle replacements, and script mods. Only install mods from verified sources linked in our Discord.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository with your **device model**, **HarmonyOS version**, and a **log file** from the launcher's `Logs` menu. Screenshots and video capture make debugging much faster.
</details>
